## About

I'm **giinyu** — an independent builder working at the intersection of **media software, API integrations, performance optimization and interface design**.

My current focus is extending the media ecosystem: connecting applications that should work together, building source plugins, improving desktop responsiveness, and designing interfaces that feel good to use without sacrificing performance.

I work with open-source projects through hands-on testing, iterative development, reproducible builds and AI-assisted engineering workflows. I care about the details that turn a working prototype into something people actually want to use.

## Current work

### 01 / RE-Harbor — desktop media platform

[Repository](https://github.com/G1NYU/RE-Harbor) · [Open experiments](https://github.com/G1NYU/RE-Harbor/pulls)

My experimental fork of Harbor, with work across the React/TypeScript frontend, Tauri desktop environment and media integrations.

| Initiative | Engineering focus | Status |
| :--- | :--- | :--- |
| [Refract integration](https://github.com/G1NYU/RE-Harbor/pull/4) | API-key authentication, external-ID resolution, persistent watch-event queues, duplicate protection and inbound watched history | Experimental; manual watch logging verified live |
| [Automatic diary logging](https://github.com/G1NYU/RE-Harbor/tree/feature/snappy-startup-msi) | Configurable time and completion thresholds using existing playback events | In testing |
| [Snappy](https://github.com/G1NYU/RE-Harbor/pull/5) | Deferred initialization, lazy poster mounting, scroll/render diagnostics, isolated Windows MSI builds | Experimental builds |
| [VOID Native](https://github.com/G1NYU/RE-Harbor/pull/6) | Component-level theming and a first-class alternative to runtime UI overrides | Prototype |

The longer-term goal for Refract is a unified media tracker, with watchlist synchronization next and games, reading and manga support dependent on future API capabilities.

### 02 / Harbor Plugins — source development & distribution

[Repository](https://github.com/G1NYU/harbor-plugins) · [Live catalog](https://g1nyu.github.io/harbor-plugins/)

An actively maintained fork with multilingual manga and Western comics source adapters, alongside the existing plugin infrastructure.

- TypeScript provider implementations in a constrained worker runtime.
- HTML/JSON parsing, pagination, metadata normalization, cover resolution and reader image extraction.
- Real-client testing of search, catalog loading and deep chapter archives.
- Separate testing and main catalogs, esbuild bundling, manifest validation and GitHub Pages deployment.

### 03 / VOID — design with a performance budget

A custom Harbor theme project exploring cinematic media interfaces, restrained Catppuccin Mocha palettes, bespoke navigation icons, typography and multilingual layouts.

The original rich-effects experiments led to a lighter, static CSS approach, guided by real scrolling tests and frame-timing diagnostics. The native component experiment is a separate work in progress.

**Design principle:** a beautiful interface is only worth keeping if it remains responsive.
